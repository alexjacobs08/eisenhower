# Eisenhower Matrix

A small, single-page Eisenhower matrix you can mark up.

**Live:** https://alexjacobs08.github.io/eisenhower/

- Click anywhere on the matrix to add a task, then drag it around. Position is continuous: the further left, the more urgent; the higher up, the more important.
- Dump everything into **Brain dump** first (paste a multi-line list to add many at once), then drag each one onto the matrix or tap it and tap the matrix.
- The side list sorts tasks by quadrant and by how close they sit to the top-left corner. Tick them off as you go.
- **Copy link** encodes the whole board in the URL, so you can share it without a server.
- **Copy as list** puts a Markdown checklist on your clipboard.
- Keyboard: Tab to a dot, arrow keys move it (Shift for bigger steps), Enter edits, Delete removes, Cmd/Ctrl+Z undoes a delete or clear.

Everything is saved in your browser's localStorage. No build step, no dependencies: it's one `index.html`.
